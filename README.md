# 🏎️ Nitro Racer

A fast-paced 3D racing game built with Three.js where you dodge AI cars, collect nitro boosts, and race for the highest score!

## 🎯 Game Features

- **3-Lane Racing**: Switch between left, center, and right lanes to avoid traffic
- **Nitro Boost System**: Collect boost pads and activate nitro for double speed
- **AI Traffic**: Dodge color-coded AI cars that get faster as your score increases
- **Progressive Difficulty**: Speed ramps up the longer you survive
- **Score System**: Earn points for distance traveled and boost pads collected
- **Responsive Design**: Plays on any screen size (desktop recommended)
- **Placeholder Art**: Runs immediately with procedural graphics, upgrade with custom assets

## 🎮 How to Play

### Controls
| Key | Action |
|-----|--------|
| **A** or **←** | Move left |
| **D** or **→** | Move right |
| **SHIFT** (Left or Right) | Activate nitro boost |
| **SPACE** | Start game / Restart after crash |

### Objective
- **Avoid** colliding with AI cars
- **Collect** golden boost pads (stars) to refill your nitro meter
- **Use** nitro boost strategically to maximize your score
- **Survive** as long as possible - speed increases over time!

### HUD
- **Speed**: Current speed in km/h (nitro doubles it!)
- **Nitro Bar**: Orange fuel meter (collect pads to refill, recharges slowly over time)
- **Score**: Your current score based on distance + pickups
